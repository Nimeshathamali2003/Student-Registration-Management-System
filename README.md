# Student Registration Management System

## 📋 Project Overview

**Project Title:** Student Registration Management System of H/ Konkarahena K.V

**Institution:** Sri Lanka Institute of Advanced Technological Education (SLIATE) – Advanced Technological Institute of Tangalle

**Student:** U.G. Nimesha Thamali

**Registration No:** TAN/2023/IT/F/0044 (TAN/2324/IT/F/0044)

**Supervisor:** Mr. G.R.C. Kumara

**Date:** 30/01/2025

---

## 📖 Introduction

The **Student Registration Management System** is a database-driven application developed for **H/ Konkarahena K.V** to efficiently manage student registrations and academic records. The system replaces the traditional manual record-keeping method with a centralized, accurate, and user-friendly digital solution using **Microsoft Access**.

Like many schools, Konkarahena K.V faced significant challenges in efficiently managing student registrations, maintaining accurate student records, and streamlining school administration. This project addresses these challenges by providing a well-organized registration system.

---

## 🎯 Objectives

- To design and develop a centralized database system for managing student registrations
- To maintain accurate and up-to-date student records
- To streamline school administrative processes
- To enable efficient retrieval and reporting of student information
- To improve the overall efficiency of the school's registration system

---

## 💻 System Requirements

| Component | Specification |
|-----------|--------------|
| Hardware | Intel Core i3 laptop, Android-based smartphone |
| Operating System | Windows 7 |
| Database Software | Microsoft Access |

---

## 🗄️ Database Components

The system includes the following database objects:

| Component | Description |
|-----------|-------------|
| **Tables** | Store all data |
| **Forms** | User-friendly data entry interfaces |
| **Queries** | Retrieve and manipulate data |
| **Reports** | Present formatted data for printing/viewing |
| **Relationships** | Connect tables for data integrity |

---

## 📊 Database Tables (6 Tables)

### 1. Student Details
Stores personal information of students:
- Student ID (Primary Key)
- First Name, Last Name
- Date of Birth
- Gender
- Address
- Contact Number
- Email
- Class ID

### 2. Academic Year Details
Manages academic year information:
- Academic Year ID (Primary Key)
- Academic Year
- Start Date
- End Date

### 3. Class Details
Stores class-related information:
- Class ID (Primary Key)
- Class Name
- Grade
- Section
- Class Teacher

### 4. Registration Details
Tracks student registrations:
- Registration ID (Primary Key)
- Student ID (Foreign Key)
- Class Name
- Registration Date

### 5. Student Academic Year Details
Links students to academic years:
- Student ID (Foreign Key)
- Academic Year ID (Foreign Key)

### 6. Student Contact Number Details
Stores contact numbers:
- Student ID (Foreign Key)
- Contact Number

---

## 📝 Forms (3 Forms)

| Form | Purpose |
|------|---------|
| **Student Form** | For entering and viewing student details |
| **Class Form** | For managing class information |
| **Registration Form** | For handling student registrations |

Each form includes **Design View** and **Form View** for development and user interaction.

---

## 🔍 Queries (5 Queries)

| Query | Purpose |
|-------|---------|
| **Female Students Query** | Retrieves all female students |
| **Male Students Query** | Retrieves all male students |
| **Grade 6 Query** | Retrieves Grade 6 students |
| **Academic Year 2024 Query** | Retrieves records for academic year 2024 |
| **Section as Ascending Query** | Sorts sections in ascending order |

---

## 📄 Reports (2 Reports)

| Report | Purpose |
|--------|---------|
| **Student Registration Report** | Displays student registration details |
| **Grade & Section Report** | Groups students by grade and section |

---

## 🔗 Relationships

The database uses relationships to ensure data integrity and enable efficient retrieval of related information.

**Relationship Types:**
- One-to-One
- One-to-Many
- Many-to-Many

**Connections:**
- Student ↔ Registration
- Student ↔ Class
- Student ↔ Academic Year
- Student ↔ Student Contact Number
- Student ↔ Student Academic Year
